# PlaySim — Prediction Market

A full-stack educational YES/NO prediction market using simulated currency. Built with Django REST Framework, PostgreSQL, Django Channels, Redis, React, Vite and Docker Compose.

Features include price-time priority order matching, partial fills, limit and protected market orders, virtual wallet reservations, positions, portfolio views, real-time book updates, market resolution, settlements, dispute workflow, simulated market making and property-based matching tests.

This is a learning prototype for simulated currency only, not audited financial software. It has no real-money deposits, withdrawals or payment integrations.

See the project files and Docker Compose setup for local development.
